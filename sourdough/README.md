# Sourdough

Wild yeast + lactic acid bacteria. Slower, more flavorful, more flexible than commercial yeast — and once the workflow clicks, less work, not more.

## Contents

- **[`course/`](course/)** — **start here if you're new.** A 4-week beginner course that takes you from zero to a healthy starter, weekly DEAM rhythm, and three real bakes.
- **[`methods/double-enzymatic-activation.md`](methods/double-enzymatic-activation.md)** — the headline method. Cold-fed levain workflow, enzyme-staged timing, low effort, high flavor. The reference document the course works toward.
- **[`starter.md`](starter.md)** — starter and cold-fed levain maintenance: weekly schedule, feed math, storage, troubleshooting, maturity timeline.
- **[`flour-selection.md`](flour-selection.md)** — protein, ash, milling, additives, hydration behavior. How to pick flour for what you're trying to make.
- **[`recipes/`](recipes/)** — worked recipes that apply the method.
