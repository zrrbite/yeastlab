# Sourdough recipes

Worked recipes that apply the [Double Enzymatic Activation method](../methods/double-enzymatic-activation.md). Each one is a starting ratio, not a rulebook — read the method and the [theory](../../theory/) once and you'll see where the dials are.

## Index

### Bread

- **[`baguettes.md`](baguettes.md)** — French-style baguettes on a 3-day cold-fed levain, long early cold rest, short bulk.
- **[`italian-country-loaf.md`](italian-country-loaf.md)** — the "no shaping, no scoring, no BS" rustic boule featured in the original DEAM doc. 4-day-old levain, 4-hour bulk, single fold.
- **[`ciabatta.md`](ciabatta.md)** — high-hydration, dramatic open crumb, Italian-style. Demands wet-hand technique.

### Flat / quick breads

- **[`focaccia-weekday.md`](focaccia-weekday.md)** — 1–2 day weekday-friendly focaccia that exploits the cold rest for a do-nothing schedule.
- **[`pita.md`](pita.md)** — soft, puffy, pocketed flatbreads. 3 hours from a prepped levain. Stove-top option included.

### Pizza

- **[`pizza-neapolitan.md`](pizza-neapolitan.md)** — Naples-style for high-temp pizza ovens (430–500 °C, 60–90 sec bake). Soft, leopard-spotted, no oil/sugar.
- **[`pizza-ny.md`](pizza-ny.md)** — NY-style for home ovens (260–290 °C, 6–8 min). Bread flour, oil, sugar, foldable slice. 48–72 hr cold rest.

### Discard

- **[`discard-rolls.md`](discard-rolls.md)** — soft dinner rolls from sourdough discard + commercial yeast. Same-day, 3 hours start-to-warm. The "what to do with all this discard" answer.
