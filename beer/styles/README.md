# Styles

Style definitions and comparison content. Each style file covers history, defining traits, vital stats, grain/water/yeast/hops, process pipeline, and what good and bad look like.

## Contents

### IPA family

- **[`neipa.md`](neipa.md)** — New England IPA. Hazy, juicy, soft, biotransformation-driven.
- **[`west-coast-ipa.md`](west-coast-ipa.md)** — West Coast IPA. Clear, dry, piney, citrusy, bitter.
- **[`cold-ipa.md`](cold-ipa.md)** — lager-yeast IPA. Brilliantly clear, very dry, extremely hop-forward.
- **[`comparison.md`](comparison.md)** — NEIPA vs WCIPA vs Cold IPA at a glance with decision matrix.

### Other styles

- **[`saison.md`](saison.md)** — Belgian/French farmhouse ale. Yeast-driven, dry, peppery, versatile.
- **[`pilsner.md`](pilsner.md)** — Czech and German pilsner. The most-consumed style globally; the hardest to brew well.
- **[`stout.md`](stout.md)** — the dark family. Irish dry / oatmeal / sweet / American / imperial / pastry / barrel-aged.
- **[`mixed-fermentation.md`](mixed-fermentation.md)** — sour and wild beers. Brett, LAB, lambics, kettle sours, modern wild ales.

## Reading order

If you're new to the breadth of beer styles:

1. **Start with what you drink most.** If you love NEIPAs, start there. If pilsner, there.
2. **Then read its closest sibling** for context (NEIPA → WCIPA → Cold IPA, or Pilsner → Cold IPA, or Saison → mixed-fermentation).
3. **Read `comparison.md`** for orientation across the IPA family.
4. **Branch out by curiosity.**

## What's not here yet

- **English styles** (Bitter, ESB, Mild) — covered briefly in stout.md, but no dedicated file
- **Belgian Dubbel / Tripel / Quadrupel** — significant style family, deserves files
- **Sour-leaning styles** (Berliner Weisse, Gose) — covered briefly in mixed-fermentation.md
- **Lager substyles** (Helles, Märzen, Doppelbock, Kellerbier) — Pilsner is the only lager covered in depth
- **American Pale Ale, Amber Ale, Brown Ale** — sister styles to WCIPA; mostly covered there

If you brew a style not here and want to add it, the template is: vital stats + grain/water/yeast/hops + process + sensory targets + failure modes.
