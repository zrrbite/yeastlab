# Styles

Style definitions and comparison content. Each style file covers history, defining traits, vital stats, grain/water/yeast/hops, process pipeline, and what good and bad look like.

## Contents

- **[`neipa.md`](neipa.md)** — New England IPA. Hazy, juicy, soft, biotransformation-driven. The dominant modern style.
- **[`west-coast-ipa.md`](west-coast-ipa.md)** — West Coast IPA. Clear, dry, piney, citrusy, bitter. The American IPA original.
- **[`comparison.md`](comparison.md)** — NEIPA vs WCIPA (modern + classic) vs Cold IPA at a glance. Useful when deciding which to brew or comparing recipes.

## More styles to come

The repo is currently IPA-focused because that's where the headline interest is. Other styles that would expand this folder:

- Cold IPA (lager-yeast IPA)
- Brut IPA (very dry, wine-yeast-like)
- Hazy DIPA / TIPA (bigger NEIPA)
- Saison (mixed-microbiology farmhouse)
- German Pilsner / Czech Pilsner
- Stout / Imperial Stout
- Mixed-fermentation / sour styles

If you brew a style that isn't here and want to add it, the template is: vital stats + grain/water/yeast/hops + process + sensory targets + failure modes. See `neipa.md` and `west-coast-ipa.md` as references.
