# Hop variety deep dives

Single-variety files going deeper than the [`../varieties.md`](../varieties.md) reference. Each covers pedigree, full oil/acid composition, sensory profile (including lot-to-lot variation), biotransformation behavior, hop pairings, substitutions, recipe positioning, and common mistakes.

These are the varieties that **drive most of modern hop-forward brewing**. Other varieties are covered at quick-reference depth in the parent `varieties.md`.

## Contents

- **[`citra.md`](citra.md)** — the defining hop of modern American IPA
- **[`galaxy.md`](galaxy.md)** — Australia's flagship; the most thiol-rich common hop
- **[`mosaic.md`](mosaic.md)** — Citra's foundational pairing partner; dank/blueberry depth
- **[`nelson-sauvin.md`](nelson-sauvin.md)** — the Sauvignon Blanc hop; uniquely wine-like

## When to read which

- **Designing a recipe with one of these as the lead hop** → read its deep dive
- **Substituting a variety** → check the dive's substitutions section
- **Evaluating quality of a new bag** → reference the sensory profile section + [`../sensory-analysis.md`](../sensory-analysis.md)
- **Wondering why a pairing works or doesn't** → cross-reference the pairings sections
