# Beer

Brewers yeast — *Saccharomyces cerevisiae* (ales), *S. pastorianus* (lagers), *Brettanomyces*, mixed cultures, and the occasional kveik. Same enzymes as bread (see [`../theory/bread-vs-beer.md`](../theory/bread-vs-beer.md)), different staging: a hot mash to liberate sugars, a long ferment in liquid, then conditioning.
